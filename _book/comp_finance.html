2.4 Updating the expectation

  • Unconditional:

\[ \mathbf{E}^Q [X] = \sum_{\omega_k \in \Omega} X(\omega_k) \mathbf{Q}(\omega_k) \]

  • We can use conditional expectation to narrow down the outcomes, if we condition on the particular element \(f^t_h\), formally:

\[\mathbf{Q}[\omega_k \mid f^t_h] = \frac{\mathbf{Q}[{\omega_k} \cap f^t+h]}{\mathbf{Q[f^t_h]}} = \begin{cases} \frac{\mathcal{Q}[\omega_k]}{\mathcal{Q}[f^t_h]} \; \text {if} \; \omega_k \in f^t_h \\[1pt] 0 \; \text{otherwise} \end{cases} \]

The idea is that we can infer the value of rv precisely if we know we are operating wihin a information subset f. 

  • Use \(\mathbf{E}^Q [X \mid \mathcal{P_t}] (f^h_t) = \sum_{w_k \in f^h_t} X(\omega_k) \frac{\mathcal{Q}[\omega_k]}{\mathcal{Q}[f^t_h]}\) instead of unconditional prob.

  • Conditioning on the set in \(t = 0, \mathcal{P_0}\) does not modify the unconditional formula, no refinement occurs.

  • Given that \(X\) is \(\mathcal{P_i}\)-measurable, we can take it out of the expectation to obtain \(\mathbf{E^Q [ \mathcal{X} \mid \mathcal{P_i}] = \sum_{\omega_k \in \Omega} X(\omega_k) \frac{\mathbf{Q}[\omega_k \mid f^t_h]}{\mathbf{Q}[f^t_h]} = \underbrace{\text{take out}}{\frac{X}{\mathbf{Q}[f^t_h]}} \sum_{\omega_k \in f^t_h} \mathbf{Q}[\omega_k]} = X(f^t_h)\) ` ## Properties of conditional expectation ##

3.4 Dynamic completeness

A contingent claim is ana \(\mathcal{P}-\) adapted process where \(X(t)\) is the cashflow generated by the contingent claim \(X\) at time \(t\).

The contingent claim \(X = \{ X(t) \}^T_{t = \Delta t}\) is attainable if exists a dynamic investment strategy \(v\) s.t. \[ C_v(t) = X(t), \quad t = \Delta t, \dots, T \]

equivalently:

\[ v_0(t) B(t + \Delta t) + \sum_j v_j(t) \frac{S_j(t + \Delta t)}{1 + r(t)\Delta t} - V(t) = X(t) \]

  • We say that a multi period fin market is dynamically complete id every contingent claim \(X = \{ X(t) \}^{T}_{t = \Delta t}\) is attainable.

3.5 The second fundamental theorem of asset pricing

In a discrete multi period fin market TFAE:

  • market is both arbitrage free and dynamically complete
  • there exists one and only one equivalent martingale measure

4.4 European barrier option

The payoff is specified:

\[ X_{ko} (t) = \begin{cases} 0 \text{ if triggered } \\ X \text{ if not triggered} \end{cases} \]

Or (knock in)

\[ X_{ko} (t) = \begin{cases} X \text{ if triggered } \\ 0 \text{ if not triggered} \end{cases} \]

Define the running max of S :

\[ \begin{align} M(t) &= max\{ S(u): u \leq t \} \text{ running max of S for } u \in (0,t) \\ X_{KO} &= \begin{cases} 0 \text{ if } S \geq b \\ X \text{ othereise} \end{cases} \\ X &= X_{KI}(t) + X_{KO} (t) \\ V(t) &= V_{KI} (t) + V_{KO} (t) \end{align} \]

We can apply backward recursion to barrier options:

\[ \hat{V}_{KO} (t) = X \mathbf{1}(S(t) < b) \]

Now, we want to prove that we can use the price instead of running maximum to derive the fair value of the option.

\[ V_{KO} (0) = E^Q [X \mathbf{1}_{M(t) < b}] = \hat{V}_{KO}(0) \]

  1. Split the indicator function for multiple periods:

\[ \mathbf{1} (M(T) < b) = \prod_{i = 1}^T \mathbf{1} (S(t_i) < b) \]

  1. Substitute 1. in the expectation:

\[ V_{KO} (0) = E^Q [ X \mathbf{1} (M(2) < b)] = E^Q [ X \mathbf{1} (S(1) < b) \mathbf{1} (S(2) < b) ] = E^Q [ \mathbf{1} (S(1) < b) E^Q_1 [ X \mathbf{1} (S(2) < b)]] \]

At each recursive node i in (0, T), we get \(\hat{V}_{KO} (i)\) as the inner terms. What about knock in options?

\[ V_{KI} (0) = V(0) - V_{KO} (0) = V(0) - \hat{V}_{KO} (0) \]
