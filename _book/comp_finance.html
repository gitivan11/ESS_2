2.1 Market discrete time

  • Risky: return ukknown
  • Riskless: known at \(t - \Delta t\)
  • Locally riskless interest - \(r(t)\) the net rate of return berween $ t and t + $ -$ $ set of events

P-probability measure, distributon over risky assets defining investors’ beliefs - historical probability

\[ \mathbb{E}^{\mathcal{P}} [ S(t)] = \sum_{w_k \in \Omega} S(t) (w_k) P (w_k) \]

2.2 Information structure

  • Definition of partition, finer/coarser
  • Information structure: sum to the state space; refinement occurs over time, formally \(\mathcal{P}_{t + \Delta t}\) is finer than \(\mathcal{P}\) for all t.
  • \(f^h_t\) denotes a node of the partition (h element of information set at time t)

2.3 Information evolution

  • Risky quantity \[ \mathrm{X}: \Omega \to \mathbf{R} \]

  • Known quantity? -> based on \(\mathcal{P}\), we know its relaization. if \(w_k, w_j \in f^t_h\), then \(X(\omega_k) = X(\omega_j)\)

  • \(\mathbf{X}: \mathcal{P}_t \to \mathcal{R}\)

  • Conditioning on the element of the partition, X is known with certainty. In other words, X is P-measurable. Define measurability!

We need to define a sequence of random variables over time, so we turn to stochastic processes.

  • Stochastic process:

\[ Y = \{ Y(t) \}^T_{t = 0} \]

such that \(Y(t): \Omega \to \mathcal{R}\) is adapted to \(\mathcal{P}\) if \(Y(t)\) is \(\mathcal{P}_t\) - measurable for all t.

2.4 Updating the expectation

  • Unconditional:

\[ \mathbf{E}^Q [X] = \sum_{\omega_k \in \Omega} X(\omega_k) \mathbf{Q}(\omega_k) \]

  • We can use conditional expectation to narrow down the outcomes, if we condition on the particular element \(f^t_h\), formally:

\[\mathbf{Q}[\omega_k \mid f^t_h] = \frac{\mathbf{Q}[{\omega_k} \cap f^t+h]}{\mathbf{Q[f^t_h]}} = \begin{cases} \frac{\mathcal{Q}[\omega_k]}{\mathcal{Q}[f^t_h]} \; \text {if} \; \omega_k \in f^t_h \\[1pt] 0 \; \text{otherwise} \end{cases} \]

The idea is that we can infer the value of rv precisely if we know we are operating wihin a information subset f. 

  • Use \(\mathbf{E}^Q [X \mid \mathcal{P_t}] (f^h_t) = \sum_{w_k \in f^h_t} X(\omega_k) \frac{\mathcal{Q}[\omega_k]}{\mathcal{Q}[f^t_h]}\) instead of unconditional prob.

  • Conditioning on the set in \(t = 0, \mathcal{P_0}\) does not modify the unconditional formula, no refinement occurs.

  • Given that \(X\) is \(\mathcal{P_i}\)-measurable, we can take it out of the expectation to obtain \(\mathbf{E^Q [ \mathcal{X} \mid \mathcal{P_i}] = \sum_{\omega_k \in \Omega} X(\omega_k) \frac{\mathbf{Q}[\omega_k \mid f^t_h]}{\mathbf{Q}[f^t_h]} = \underbrace{\text{take out}}{\frac{X}{\mathbf{Q}[f^t_h]}} \sum_{\omega_k \in f^t_h} \mathbf{Q}[\omega_k]} = X(f^t_h)\) ` ## Properties of conditional expectation ##

  • Linearity

  • Tower property

2.5 Independent random variables

  • definition of independence of variable and information set wrt probability measure \(\mathcal{P}\)

  • it holds that \(X\) is independent of \(\mathcal{P}_t\) wrt \(Q\) iff X takes all possible number of realizations on any \(f^t_h \iin \mathcal{P}_t\) (weak independence)

  • \(E^Q [ X \mid \mathcal{P}_t] (f^t_h) = E^Q [ X ]\) for all \(f^t_h \in \mathcal{P}_t\)

  • martingales: \[ M = \{M(t) \}^T_{t=0} \; \text{adapted to} \; \mathcal{P} = \{ \mathcal{P_t} \}^T_{t = 0} \; \; \text{is a martingale if} \forall t_i, t_{i+1} \; \text{we have} \]

\[ \mathbf{E}^Q [M(t_{t_{i+1}}) \mid \mathcal{P_{t_i}}] = M(t_i) \]

  • meaning: the best forecast of the process at time \(t + \Delta t\) is the forecast itself at time \(t\).

2.6 Risky vs riskless

  • Dynamic investment strategies: \(v\) is a \(d+1\) dimensional \(\mathcal{P}\)-adapted process \(v_j = \{ v_j(t) \}^{T - \Delta t}_{t = 0}\) with \(j = 0,1,...,d\) where \(v_j(t)\) is the number of units of security \(j\) at time \(t\) based on information \(\mathcal{F}_t\)

  • Value Process: the value process of \(v\) is denoted by \(V_v = \{ V_v(t) \}^T_{t = 0}\) is defined as the following stochastic process:

\[V_v(t) = \begin{cases} v_0(t) B(t) + \sum_i^d v_i (t) S_i (t) \; \; t = 0, \dots, T - \Delta t \\ v_0(T - \Delta t) B(T) + \sum_{i = 1}^d v_i (T - \Delta t) S_i (T), \; \; t = T \end{cases} \]

-Explanation: ???

  • Cash flow process:

\[C_v (t) = \begin{cases} - V_v(0) \text{ initial negative outflow to buy} \qquad t = 0 \\ v_0 (t - \Delta t) B(t) + \sum_{i = 1}^{d} v_i (t - \Delta t)S_i(t) - V_v (t) \qquad t = \Delta t, \dots, T - \Delta t \\ V_v(T) \qquad t = T \end{cases} \]

-Explanation: ??

  • Self-financing strategies: dynamic strategy is self financing if \(C_v(t) = 0, \quad t = \Delta t, \dots, T - \Delta t\) It follows from definition of cash flow process:

\[ v_0 (t - \Delta t) B(t) + \sum_{i = 1}^{d} v_i (t - \Delta t)S_i(t) = V_v(t) \]

  • Discounted Gain Process: for strategy \(v\) we call DGP \(\{G_v\} = \{ G_v (t) \}^T_{t = 0}\) the stochastic process defined as:

\[ G_v(t) = \begin{cases} \frac{V_v(t)}{B(t)} + \sum_{\tau = 0}^t \frac{C_v (\tau)}{B(\tau)} \qquad t = 0, \dots, T - \Delta t \\ \sum_{\tau = 0}^T \frac{C_v(\tau)}{B(\tau)}, \qquad t = T \end{cases} \]

2.7 Anomalies

  • Violations of LOP: if there exist two dyn investment strategies \(v\) and \(v'\) delivering the same cash flows for all t \(C_v(t) = C_{v'}(t)\) for all t but \(V_v(0) \neq V_{v'}(0)\)

  • Arbitrage opportunities of the first type: if there exists a dynamic investment straetgy \(v\) such that:

\[\begin{enumerate} \item V_v(0) \leq 0 \text{ we sell an asset} \item C_v(t) \geq 0 \text{ for all t} \item \mathbf{P}(C_v(\tau)>0) > 0 \text{ for some } \tau. \]

  • explanation: suppose all C null but at least one positive, then the price must be positive so $V_v(0) > 0 $ necessarily. LOP -> arbitrage opportunities!

  • taking the PV of security j at time t
  • equivalent probabilty measures: positive probabilities assigned to \(Q\) imply positive probabilities assigned to \(\mathcal{P}\) and vice versa.
  • Goal : find Q such that no arbitrage
